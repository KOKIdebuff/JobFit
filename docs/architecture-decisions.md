# HireLink 文档入口

这是 HireLink 当前的文档索引。推荐按下面顺序阅读：

1. [prd.md](./prd.md) - 产品需求
2. [architecture.md](./architecture.md) - 技术架构
3. [roadmap.md](./roadmap.md) - 里程碑和优先级
4. [archive/HireLink决策.md](./archive/HireLink决策.md) - PDF 原文转换归档

## 说明

- `prd.md` 只描述做什么、为什么做、用户是谁、核心流程是什么。
- `architecture.md` 只描述怎么做、技术选型、系统边界、数据流、Agent 结构、安全方案。
- `roadmap.md` 只描述 MVP 顺序、P0/P1/P2 优先级、依赖关系、演示顺序。
- 原始 PDF 转换稿保留在 `archive/` 下，作为追溯来源，不作为主入口文档。
